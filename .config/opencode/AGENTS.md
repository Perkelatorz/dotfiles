# Global rules

## Memory

When you learn something durable — a project convention, a gotcha, a decision and its reason, a command that works where the obvious one doesn't — append it to that project's `AGENTS.md` under a `## Notes` section (create the file if missing). One line per fact. Don't record anything derivable from the code itself.

At session start, if the project has an `AGENTS.md`, treat its Notes as established fact.

## Task tracking

If the project root has a `TODO.md`, it is the task list of record:

- Before starting work, read it and continue from the first unchecked item unless told otherwise.
- Mark an item `[x]` in the file immediately after completing it — not in batches at the end.
- When given a new multi-step task, add the steps to `TODO.md` first, then work through them.
- Also mirror the current item into the todowrite tool so progress is visible, but the file is the source of truth — the tool's state dies with the session.
